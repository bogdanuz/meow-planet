# Планета Мяу

![Планета Мяу — мини-игры для малышей](docs/github-banner.jpg)

PWA-хаб мини-игр для детей 2–3 лет (основная платформа: iPad landscape) с офлайн-работой после первого запуска.

Закрытый (проприетарный) проект — см. [`LICENSE`](LICENSE).

## Для кого
- Дети 2–3 лет и их родители. Основной сценарий — горизонтальная ориентация на iPad и других планшетах.

## Как это работает для игрока
На хабе есть плитки игр. В portrait и на слишком маленьких экранах показываются отдельные экраны-гейты. Первый запуск загружает ассеты через Service Worker, после чего хаб и игры работают без сети.

## Адаптивность и офлайн
- Portrait: показывается экран «Поверни планшет», клики по игре отключаются.
- Слишком маленький экран/окно: показывается «Планета Мяу ждёт тебя на планшете» (min(width,height) < 720px).
- Offline: Service Worker pre-cache включает медиа/шрифты/JSON. Реальная проверка офлайн-режима выполняется на iPad после релиза (см. `BACKLOG.md`).

## PWA / офлайн

Проект использует `vite-plugin-pwa` (Workbox). В production сборке генерируется `sw.js`, а сервис-воркер обеспечивает offline-кеширование ассетов приложения.

Service Worker обновляется без диалогов (`registerType: autoUpdate`), а при новом деплое устаревшие кэши очищаются — поэтому iPad/планшеты со временем получают актуальные файлы.

## Структура проекта (кратко)

- `src/games/` — игровые модули
- `src/shared/` — общие утилиты (audio, storage, soft-error и т.п.)
- `public/` — runtime-ассеты (иконки, арт, звуки)
- `tests/` — unit/e2e
- `assets-master/` — исходники ассетов; используется для генерации и игнорируется GitHub через `.gitignore`
