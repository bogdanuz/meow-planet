# Evidence-based kids content

## Three layers (always separate)

1. **Direct source claim** — what AAP/WHO/NAEYC actually say (with URL + publication date).
2. **Product interpretation** — how we apply it to a hub for 2–3 y.o.
3. **Internal conservative choice** — our UX/session design (not presented as medical fact).

## Primary sources (URLs only — do not paste full policy text)

See [references/sources.md](references/sources.md). Prefer AAP, WHO, NAEYC for general guidance.

## Rules

- No claim that AAP/WHO set **one mini-session length** if the source only addresses **daily** screen time.
- Do not infer **this game's efficacy** from general screen-time guidance.
- Weak or missing source → soften wording; label as hypothesis, not science.
- Per game (in `docs/games/` or evidence folder): learning goal, age/prerequisites, mechanic, co-play prompt, offline extension, limits, source URLs, publication date, **last-reviewed** date.

## Workflow

Before approving parent-facing or educational copy: check sources.md, update `last-reviewed` when re-checked.
