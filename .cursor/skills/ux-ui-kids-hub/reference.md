# UX/UI reference — Планета Мяу

## Self-check (перед «готово»)

- [ ] Есть **один** визуальный герой / одно главное действие?
- [ ] Центр экрана не «дыра»?
- [ ] Детские tap-цели ~56–64 CSS px (или крупнее для главного CTA) и достаточный зазор между целями?
- [ ] Ребёнок может угадать действие **без чтения**?
- [ ] Нет дубля заголовка / подсказки с тем же текстом в chrome?
- [ ] Нет emoji/фейкового «арта», который выглядит как финал?
- [ ] Вторичные кнопки не спорят с Play (угол / тише)?
- [ ] Анимация зовёт к действию, а не шумит?
- [ ] Landscape-only учтён; portrait — оверлей?
- [ ] Quiet mode не ломает смысл (можно убрать пульс)?

## Антипаттерны (уже ловили на проекте)

| Ошибка | Почему плохо для 2–3 лет | Как правильно |
|---|---|---|
| Мелкий title + пустой центр + мелкие кнопки внизу | Нет якоря взгляда | Title или CTA — герой, заполняет середину |
| Три одинаковых розовых круга | Нет иерархии | Play >> звук/родители |
| Emoji в круге «как Мяу» | Выглядит недоделанным и как финал | Силуэт/градиент-blob или слот под PNG |
| «Тапни куда угодно» без метки | Ребёнок не знает, что интерактивно | Явный крупный Play + короткая подсказка у него |
| Chrome с тем же названием, что и hero | Шум, дубль | На welcome chrome скрыт |
| Скролл всей страницы меню | Ломает ощущение «мира» | Скролл только у grid плиток |

## Иерархия размеров (ориентир iPad landscape)

| Роль | Размер |
|---|---|
| Brand title | clamp ~2.5–5rem, центр/верх-центр |
| Child action targets | ~56–64 CSS px минимум; больше зазор между соседними |
| Primary CTA (Play) | заметно крупнее вторичных (часто 72–96px+) |
| Secondary (sound/parents) | меньше, угол |
| Game tile | квадрат, сторона ≥ ~7–9rem при 2–3 колонках |

## Движение

- Idle: лёгкий bounce/пульс **только** у CTA или Мяу.
- Transition welcome→menu: короткий whoosh + scale (0.3–0.5с).
- `prefers-reduced-motion` / quiet mode: отключить декоративный пульс.

## Что отложено (не чинить молча)

- Финальный брендбук / self-host шрифты
- Финальный chrome-дизайн кнопок Домой/Назад
- Подстановка `welcome-hero.png` — после генерации владельцем
