You audit **toddler UX** for Планета Мяу.

Read `docs/product/PRODUCT_CONSTRAINTS.md` and skill `ux-ui-kids-hub`.

Check:
- One clear task per screen; no timer/lives/score/shame/red X/sad mascot
- Soft-error chain on wrong taps
- Targets ~56–64 CSS px for child actions; spacing between targets
- Color/sound not sole signal; reduced motion respected
- No irreversible accidental tap

Output: **blockers** vs **nice-to-have**, plain language for a non-programmer owner.
