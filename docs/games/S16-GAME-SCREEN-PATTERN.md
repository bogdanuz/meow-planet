# S16 — универсальный экран игры

**ЗАФИКСИРОВАНО** владельцем 26.09.2026 после «Лопни шарик».  
Эталон в коде: `src/games/balloon-pop/` (полоска, иконки, кнопки). Повтор в `src/games/sound-world/`.  
Игры **не импортируют** друг друга — копируют этот паттерн и общие куски `src/shared/ui-icon.ts`, не рисуют chrome с нуля.

## Зачем

Приёмственность: ребёнок и взрослый видят те же кнопки, что на меню и в «Лопни шарик». Не придумывать новую шапку, домик или другой стиль иконок.

## Что делать в каждой игре

| Тема | Правило | Не делать |
|---|---|---|
| **Шапка хаба** | Скрыть app chrome (заголовок, домик, Мяу-полоса). Игра рисует **свою** верхнюю полосу | Оставлять «Планета Мяу» / название игры в header |
| **Навигация** | Только **Назад** (в меню) + **Звук**. Иконки REF-04: `icon-back.png`, `icon-sound.png` через `createUiIconImg`. Класс круга — `game-chrome-btn`: 4.5rem, крем, голубое кольцо, иконка 2.85rem. Звук выкл. — та же картинка серее и с чертой | Кнопка **домик / home** внутри игры. Своя картинка назад, звука, дома или настроек. Новый SVG вместо REF-04 |
| **Стиль кнопок** | Круг **4.5rem**, крем `rgb(255 252 246 / 88%)`, голубое кольцо, мягкая тень — как в «Лопни шарик» / меню | Другой размер, цвет, обводка «на глаз» |
| **Текстовые pill** | Высота **4.5rem**, те же крем + кольцо, Fredoka, ~1.2rem (как «Свободно» / «Задание») | Мелкие серые чипы |
| **Звук выкл.** | `data-on="0"`, серая иконка + перечёркивание, `hubNavigation.onSoundToggle` | Своя иконка mute |
| **Фон** | Картинка **на весь экран** (`inset: 0`, `object-fit: cover`), под контентом | Полоска фона под chrome, пустые поля по краям |
| **Шрифт** | Тот же Fredoka, что у хаба | Другой шрифт на кнопках |
| **Код** | Копировать полоску из balloon-pop / sound-world | Новая система кнопок «потому что другая игра» |

## Оболочка

В `src/app/shell.ts` для игры без app chrome:

- `chrome.hidden = true` (как welcome, menu, balloon-pop, sound-world);
- класс `app-shell--<game>` с сеткой `1fr` и `height: 100dvh`;
- скрытый chrome не занимает место (`display: none`).

## Фон

- Свой арт игры — если он уже есть (небо шариков).
- Пока своего нет — **тот же фон меню** `public/assets/shell/menu-bg.webp` (так в «Изучаем звуки»).
- Позже свой фон кладётся **тем же способом** (на весь экран), не меняя кнопки.

## Общие кнопки хаба

Один набор на всё приложение, из листа REF-04, файлы `public/assets/ui/icons/`:

| Кнопка | Где | Файл |
|---|---|---|
| Назад | меню, заглушка, настройки, каждая игра | `icon-back.png` |
| Звук | welcome, меню, каждая игра | `icon-sound.png` |
| Домой | только общая шапка хаба, не внутри игры | `icon-home.png` |
| Настройки | welcome, меню и «Рисовалка» (правый угол); шестерёнка к тем же настройкам, «Назад в игру» возвращает | `icon-settings.png` |

Новая игра берёт эти кнопки тем же `createUiIconImg` и классом `game-chrome-btn`. Не рисовать их заново и не менять размер от игры к игре. В «Рисовалке» (01.10.2026): слева «Назад» и «Звук», по центру «Отменить» и «Заново», справа «Фон», «Галерея», «Настройки».

Инструменты конкретной игры (кисть, палитра, заливка) — свои картинки. Под картинкой короткая подпись для взрослого, тем же шрифтом Fredoka. Назад и звук остаются без подписи, как в «Лопни шарик».

## Не универсально (только своя игра)

Мяу-ведущий и речь, неоновая подсказка шарика, режимы «Свободно / Задание», сетка карточек — не копировать слепо. Копировать **рамку экрана** (фон + назад + звук + стиль кнопок).
