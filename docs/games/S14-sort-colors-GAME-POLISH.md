# S14 game-polish — «Куда положить?» (sort-colors)

**Дата:** 24.09.2026 · **Статус:** **S14 ЗАВЕРШЕНО** (код **0.15.5**; арт S16 — `sort-colors-ART.md`)

## Механика (актуально)

| Элемент | Решение |
|---|---|
| Признак | **Форма** (в корзину только такая же картинка); **цвет связан 1:1 с формой** — 5 как «Лопни шарик» |
| Корзинки | Цвет рамки + **иконка формы**; подпись **Мячик · Кубик · Пирамидка · Сердечко · Звёздочка** (не цвет) |
| Игрушки | 5 типов × 2 шт.; каждый тип — **одна форма + один цвет** (не смешиваем) |
| Touch | Крупные плитки (~4.25–6.25 rem), сетка 5 корзин |
| Chrome | **`app-shell--sort-colors`**: Мяу скрыт; подсказки только в **`chrome__hint`** (тост) |
| Похвала | `praise.ts` — только «Отлично!» / «Здорово!»… **без** «в … корзинку»; раунд: «Все игрушки на месте!» |
| Пауза после партии | 1,5 с → новая партия; голос mp3 — S16 (можно унифицировать с шариками) |

## Педагогика / рынок

- 2–3 года: один признак (**форма** / «та же картинка»), крупные цели, soft return.
- Цвет помогает узнать пару, но **не** отдельное правило; подпись корзинки — слово фигуры.
- Фрукты не используем — двусмысленный цвет.
