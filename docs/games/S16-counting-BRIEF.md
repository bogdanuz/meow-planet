## Рынок (что работает у детей 2–3 лет)

| Пример | Приём | Что берём |
|---|---|---|
| Endless Numbers | Нажал цифру — она говорит своё имя и показывает столько же предметов | Цифра всегда рядом с количеством |
| Numberblocks (BBC) | Числа из кубиков: добавил кубик — стало следующее число, убрал — предыдущее | «Положил — стало больше, убрал — меньше» как сюжет, а не вычитание |
| Монтессори «коробка с веретёнами» | Ячейки с цифрами, кладёшь столько палочек, сколько написано | Ящик с цифрой на наклейке = задание «положи столько» |
| Khan Academy Kids, Lingokids | Тап по каждому предмету — он подпрыгивает и считается вслух; «положи 3 в корзинку» | Счёт «по одному» и «дай N» |
| Sago Mini, Toca | Песочница без ошибок и таймеров | Свободная игра — основной режим |

Педагогика (осторожно, без медицинских обещаний): в 2–3 года дети чаще всего уверенно знают «один», потом «два», «три» (задача «дай N» — Wynn 1990; Sarnecka & Carey 2008). Маленькие количества 1–3 видны «с одного взгляда». Поэтому по умолчанию 1–3, взрослый открывает 1–5 и 1–10. Играть рядом со взрослым.

## Предложение Cursor (на викторину)

**Один экран, всё связано:** по центру ящик (из «Куда положить?») с наклейкой-цифрой; рядом куча игрушек; внизу — полоска цифр 1…N; ведущий хаба слева внизу.

- Положил игрушку в ящик → ведущий: «Два мячика!» (или пересчитывает все: «Раз, два — два мячика!»), цифра на ящике и в полоске загорается.
- Достал из ящика → «Один убежал! Остался один мячик».
- Нажал цифру в полоске → ведущий называет её, и ящик сам наполняется или пустеет до этого числа со счётом «раз, два, три — три!». Так панель цифр и ящик — одна игра, цифра всегда рядом с количеством.
- Тап по ящику → ведущий пересчитывает, игрушки по очереди подпрыгивают.
- «Задание»: «Положи в ящик две звёздочки» (на ящике цифра 2) → праздник; дальше по желанию «Сколько в ящике?», «Добавь ещё одну», «Убери одну».
- Смена игрушек — кнопка-плитка «Игрушки» в шапке справа с картинкой текущей игрушки.

Ниже — решения викторины.

## Концепция режимов (предложение Cursor для тура 1Б)

Экран общий: шапка S16, ведущий хаба слева внизу, по центру большой ящик, рядом на коврике несколько игрушек одного вида, внизу панель цифр 1…N.

**«Свободно»** — без заданий и ошибок: перетащил (или тап по игрушке → по ящику) в ящик — «Один кубик!», «Два кубика!», ящик показывает, сколько внутри; достал — «Остался один кубик», пусто — «Пусто!»; тап по цифре — ведущий её называет; тап по ящику — пересчёт «Раз, два — два кубика!» (игрушки подпрыгивают); кнопка «Игрушки» в шапке меняет вид игрушек.

**«Задание»** — короткие задания по одному, без «неправильно»:
- «Положи в ящик две звёздочки» — на ящике наклейка 2; ровно 2 — похвала; лишняя — «Ой, три! Давай одну достанем».
- «Посчитаем!» — 3 игрушки на коврике, тап по каждой: подпрыгивает, получает номер, «раз, два, три — три мячика!».
- «Добавь ещё одну» / «Убери одну» — «Было два, стало три!».
- «Сколько в ящике?» — тап по цифре; не та — считаем вместе, нужная цифра светится.
- «Где больше?» — два ящика (1 и 3), тап по ящику; не тот — «Давай посчитаем: тут один, а тут три».

## Решения викторины

### Тур 1 — как устроена игра (ЗАФИКСИРОВАНО 03.10.2026, частично)

| Тема | Решение |
|---|---|
| Режимы (`cnt_task_mode=switch`) | Два режима — «Свободно» и «Задание», переключатель в шапке, как в «Куда положить?» |
| Задания (`cnt_tasks`) | «Положи в ящик N», «Посчитаем!» (тап по одной), «Добавь ещё одну / Убери одну», «Сколько в ящике?», «Где больше?» |
| Диапазон (`cnt_range=r3_default`) | По умолчанию до 3; в настройках игры «до 3 / до 5 / до 10» |
| Панель цифр (свой вариант) | Интерактивная: нажал цифру — ведущий её называет. Ящик — отдельно, для того чтобы класть игрушки |
| Ящик (свой вариант) | Большой, в него кладут несколько игрушек (не все), выглядит органично; положил кубик — «Один кубик!» |
| Экран (свой вариант) | Владелец просит Cursor предложить, как устроить свободный режим и задания → тур 1Б |

### Тур 1Б — свободный режим и задания (ЗАФИКСИРОВАНО 03.10.2026)

Концепция режимов выше принята.

| Тема | Решение |
|---|---|
| Игрушек на коврике (`free_pile=max`) | Ровно столько, до скольких считаем (3 / 5 / 10). Все переложил — «Все кубики в ящике! Три кубика!» и маленький праздник |
| Что показывает ящик (`free_box_shows=digit`) | Крупная цифра-наклейка на ящике, меняется вместе со счётом; при 0 цифры нет |
| В «Свободно» (`free_actions`) | Достать обратно — «Остался один кубик», пусто — «Пусто!»; тап по ящику — пересчёт, игрушки подпрыгивают; тап по цифре — ведущий называет, цифра подпрыгивает; класть перетаскиванием и тапом (игрушка → ящик), как в «Куда положить?» |
| Как идут задания (`task_flow=rotate_grow`) | Сами по кругу от простого к сложному: сначала «Положи» и «Посчитаем», потом «Добавь/Убери», «Сколько?», «Где больше?»; после каждого — короткая похвала и следующее |
| Настройки заданий (`task_settings=toggles`) | В разделе игры галочки по каждому типу; по умолчанию для 2 лет — «Положи», «Посчитаем», «Добавь/Убери» |
| Если не получилось (`task_soft=soft_talk,glow_after2`) | Мягко, без «нет»: «Ой, три! Давай одну достанем», «Давай посчитаем вместе»; после 2 попыток — сияние на нужном (как в «Прятках») |

### Тур 2 — вид и кнопки (ЗАФИКСИРОВАНО 03.10.2026)

| Тема | Решение |
|---|---|
| Фон (`look_bg=new_corner`) | Новый, генерирует Cursor по референсам комнат проекта: уютный уголок детской — пол, коврик под игрушки, на стене гирлянда-флажки и счёты, свободное место под ящик и панель цифр; владелец потом поправит |
| Смена игрушек (`look_toys_btn=tile_popup`) | Плитка «Игрушки» справа в шапке с картинкой текущей игрушки; тап — рядом ряд из 7 игрушек, выбрал — на коврике новые |
| Какие игрушки (`look_colors=kind_mixed_colors`) | Одного вида, разных цветов (красный, жёлтый, синий, зелёный) — «три кубика» |
| Цифры (`look_digits=art_digits`) | Нарисованные объёмные цифры 1–10 в стиле игрушек (гуашь, каждая своего цвета) — Cursor генерирует лист |
| Ведущий (`look_presenter=hub_presenter`) | Общий ведущий хаба слева внизу (сова или Мяу по «Общее»), облачко + голос — как в «Куда положить?» и «Прятках» |
| Шапка (`look_header`) | Слева «Назад», «Звук»; справа «Свободно» / «Задание» (как в «Куда положить?»), «Игрушки», «Заново» (в «Свободно» — все игрушки на коврик, в «Задании» — новое задание), «Подсказка» (лупа, в «Задании»), крайняя — шестерёнка → раздел «Учимся считать» (до 3/5/10, типы заданий, подсказки сами) |

### Тур 3 — голос, звуки, настройки, порядок (ЗАФИКСИРОВАНО 03.10.2026)

| Тема | Решение |
|---|---|
| Как называть количество (`voice_counts=full_phrases`) | Целиком с игрушкой: «Один кубик!», «Две звёздочки!», «Пять мячиков!» — все формы записаны голосом (7 игрушек × 10 чисел), без склейки |
| Счёт вслух (`voice_count_words=odin`) | «Один, два, три — три кубика!» — те же слова, что на цифрах |
| Звуки (`sfx=pick_drop,party,music`) | Общие «взял» / «положил»; праздник — общая мелодия (как в пазле и «Прятках»); тихая музыка игры, тише под голос. Без отдельного «динь» при счёте и «попа» на цифре |
| Раздел в настройках (`settings=range,task_types,auto_hints`) | «Считаем до» 3 / 5 / 10 (по умолчанию 3); галочки по 5 типам заданий; «Подсказки сами» вкл/выкл (6 с — повтор задания, 12 с — сияние) |
| Вход в игру (`entry=free_last`) | Сразу «Свободно» с игрушками прошлого раза (в первый раз — кубики); ведущий: «Давай считать! Положи кубик в ящик» |
| Порядок работ (`order=code_then_voice`) | Как в «Прятках»: Cursor генерирует фон, цифры и иконки, делает игру целиком (пока текст в облачке) и отдаёт список фраз; владелец записывает один трек, Cursor режет |

### После проверки владельцем (ЗАФИКСИРОВАНО 03.10.2026, код 0.20.1)

Ящик — чуть выше и левее; игрушки — только на коврике. Сделано: ящик стоит на полу слева от коврика (над облачком ведущего), коврик игры совпадает с нарисованным ковриком фона на любом экране, игрушки рядами внутри овала (в задании «Посчитай» тоже).
