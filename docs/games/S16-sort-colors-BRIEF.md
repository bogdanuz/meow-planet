# S16 — «Куда положить?» (sort-colors): бриф

**Статус: ЗАФИКСИРОВАНО** — викторина владельца 01.10.2026 (5 туров AskQuestion).  
Заменяет механику S14 (`S14-sort-colors-GAME-POLISH.md`: 5 корзинок, форма = цвет 1:1). Экран — `S16-GAME-SCREEN-PATTERN.md`.

## User story

Ребёнок 2–3 лет видит внизу кучу объёмных игрушек и несколько ящиков с наклейками. Он берёт игрушку пальцем, сова называет её, и ребёнок кладёт её в ящик с такой же картинкой. Ящики наполняются, куча тает. В режиме «Задание» сова просит конкретное: «Положи красный кубик».

## Путь ребёнка

1. Меню → плитка «Куда положить?» → экран с ящиками по центру и кучей на коврике внизу. Сова слева внизу: «Ой, всё перепуталось! Давай разложим игрушки по местам!»
2. Касается игрушки в куче. Она приподнимается, сова говорит: «Мячик!»
3. Тащит пальцем в ящик (или тапает игрушку, потом ящик). Игрушка падает в ящик и остаётся видна. Сова иногда хвалит.
4. Если ящик не тот, он покачивается «нет-нет», игрушка мягко возвращается в кучу. Сова говорит: «Это мячик. Ему нужен ящик с мячиками». После двух промахов подряд нужный ящик подсвечивается.
5. Куча разобрана. Сова хвалит, ящики подпрыгивают, через 2 с высыпаются, и сверху падает новая куча из других 4 видов.
6. Кнопка «Задание» справа вверху. Сова даёт задание, куча маленькая, ящики только под видимые виды. Сделал → похвала → новое задание, сложность растёт.

## Решения викторины

| Тема | Решение |
|---|---|
| Предметы (7) | мячик, кубик, звёздочка, пирамидка (треугольный блок, как деталь конструктора), сердечко, уточка, колечко (от пирамидки) |
| Ящики | Пластиковые, как на плитке меню. Все одного цвета: сливочно-белые. Вид сверху под ~45°, чтобы игрушки лежали внутри кучкой |
| Наклейка | На ящике крупная наклейка: предмет тёмно-синим контуром со светлой заливкой, без цвета (важна форма) |
| Сколько ящиков | Столько, сколько видов предметов на экране |
| Свободно | Куча из 4 случайных видов из 7, по 3 штуки = 12. Каждая новая куча — другой набор |
| Цвет в свободном | 4 цвета: красный, жёлтый, синий, зелёный. В одной куче у каждого вида свой цвет, 4 вида цвет не повторяют; в следующей куче цвета перемешиваются |
| Куча | Настоящая куча внахлёст внизу на коврике; взять можно любой видимый край; после взятия остальные чуть оседают |
| Раскладка | Ящики рядом по центру, куча внизу, сова в левом нижнем углу рядом с кучей. Сверху слева «Назад» и «Звук», справа «Свободно / Задание» |
| Жесты | Тащить пальцем; или тап по игрушке, потом тап по ящику |
| В ящике | Игрушка мягко падает внутрь и остаётся видна. Ящик заполняется полностью, без пустоты: чем меньше игрушек нужно, тем крупнее они внутри |
| Не тот ящик | Ящик качается «нет-нет», игрушка мягко возвращается в кучу, сова называет предмет и нужный ящик; после 2 промахов подряд нужный ящик подсвечивается. Фразы разные, в одном смысле и стиле |
| Конец кучи | Сова хвалит, ящики подпрыгивают, через 2 с высыпаются, сверху падает новая куча |
| Задания | Один предмет по форме; цвет + форма; все одного вида; все одного цвета одного вида |
| Куча задания | 5–6 предметов из 2–3 видов, ящики только под эти виды |
| Чужой предмет в своём ящике | Принимаем (разложено верно), сова напоминает задание |
| Поток заданий | Сделал → похвала → через 1,5 с новая кучка и новое задание; сложность постепенно растёт |
| Цвета в заданиях | Красный, жёлтый, синий, зелёный |
| Слово | «ящик»: «положим кубик в ящик с кубиками» |
| Тон заданий | Попеременно «Положи …» и «Давай положим …!», как в «Лопни шарик» |
| Старт свободной кучи | По очереди: «Ой, всё перепуталось! Давай разложим игрушки по местам!», «Давай наведём порядок!», «Игрушки ждут. Каждой нужен свой домик!», «Помоги мне собрать игрушки!» |
| Похвала | Чаще коротко («Отлично!», «Ура!»), иногда с именем предмета («Мячик дома!») |
| Имя при взятии | Да, одним словом: «Мячик!» |
| Говорящая голова | Да, общий `createGamePresenter` (сова / Мяу по настройке) |
| SFX | Взял — мягкий «пуп»; попал в ящик — один общий мягкий звук; не тот ящик — общий soft-miss; новая куча падает — мягкий «тудух» |
| Источник SFX | CC0, чего нет — промпты ElevenLabs Sound Effects |
| Музыка | Та же игровая, что в «Лопни шарик», тише под голос |
| Стиль предметов | Гуашь с объёмом, как кубики на плитке «Учимся считать»: вид 3/4, блик сверху слева, тень снизу справа. Не глянцевый пластик |
| Фон | Уютная детская: стена сверху, деревянный пол с ковриком снизу; куча лежит на коврике |
| Генерация предметов | 7 листов: на каждом один предмет в 4 цветах в ряд; нарезает Cursor |
| Генерация ящиков | Один пустой ящик + лист из 7 наклеек; наклейку на ящик кладёт код |
| Озвучка | Один длинный трек ElevenLabs тем же голосом, Cursor нарезает на файлы |
