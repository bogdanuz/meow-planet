# S14 — «Изучаем звуки с Мяу» (sound-world)

**Статус:** **ГОТОВО S14** (24.09.2026). **S16 рамка** — 26.09.2026. **Промпты арта** — `docs/assets/sound-world-CARD-ART.md` (животные/транспорт 1:1; инструменты карточка+play; буквы двумя листами).  

**Модули:** 2.2 + 2.8 + 2.14 · **Код:** `src/games/sound-world/`

## User story

**Как** ребёнок 2–3 лет, **я хочу** нажимать на большие картинки и сразу слышать «как это звучит» и короткое название, **чтобы** играть без «правильно/неправильно» и повторять любимые звуки сколько угодно.

**Как** родитель, **я хочу** переключать темы (животные, транспорт…) и при желании скрыть английские буквы, **чтобы** занятие было спокойным и коротким.

## Путь на экране (как сейчас + цель)

1. Меню → плитка «Изучаем звуки с Мяу».
2. Экран: **название категории** (для взрослого), **точки** (сколько тем), **сетка карточек** без подписей на картинках.
3. Ребёнок **тапает** карточку → короткий звук + **имя** (сейчас в подсказке внизу/hint; позже — голос + mp3).
4. **Смена темы:** стрелки ← → или **свайп** по области сетки; точки показывают тему без цифр.
5. Выход: **Назад** в меню + **Звук** (как в «Лопни шарик»; домика нет). Паттерн: `docs/games/S16-GAME-SCREEN-PATTERN.md`.

## Что зафиксировано в идее продукта

- Не викторина «угадай» — любой тап OK.
- Только объекты с **естественным** звуком (+ буквы RU/EN отдельной категорией).
- Карусель категорий, свайп, точки без цифр; крупные карточки.
- EN: буква без слова-примера; родитель может скрыть EN (`hideEnglishAlphabet`).
- Полный банк 106 объектов — **не все** в MVP-звуке; подмножество по ASSET-MANIFEST «Звук в 2.2».

## Рынок (паттерны, не копируем UI)

- **Монтессори / sound books:** один объект — один звук; ребёнок повторяет сам; без оценки.
- **Детские «Animal sounds» (2–4):** большие иконки, мгновенный звук, категории-вкладки; минимум текста.
- **Sago Mini / Fisher-Price style:** ярко, мало кнопок, нет «Game Over»; звук сразу после тапа (важно для iOS — unlock audio на первом жесте).
- **Чего избегают лидеры для малышей:** таймер, «ошибка», мелкие цели, чтение обязательное.

### Тур 3 — навигация (ЗАФИКСИРОВАНО)

- **Подкатегории** — тоже **кнопки**, вёрстка органично (животные: домашние/ферма/…; аналогично где нужно).
- **Стрелки / свайп** листают карточки **внутри** текущей подкатегории.
- **Дошли до конца** подкатегории → **автоматически** следующая подкатегория (и при необходимости следующая главная категория — уточнить на тур 4).
- **Код:** после **ещё одного** тура (иконки/фразы категорий).

### Тур 4 — навигация и подсказка (ЗАФИКСИРОВАНО)

- **Автолистание:** подкатегории **по кругу внутри** главной вкладки; **главную вкладку** (Животные / Транспорт / …) ребёнок меняет **только тапом** сверху.
- **Подсказка:** «Нажми на карточку — услышишь звук!»
- **Дерево категорий** = разделы **13.1–13.6, 13.11, 13.13** манифеста (только строки «Звук = да») + **Буквы** + **ABC**:

| Главная вкладка | Подкатегории-кнопки |
|---|---|
| **Животные** | Домашние · Ферма · В лесу · Экзотика · Птицы · Море |
| **Транспорт** | Наземный · Вода · Небо · Спецслужбы _(наземный/вода/небо — по типу VEH; сирены — отдельная)_ |
| **Инструменты** | _(одна подкатегория «Музыка»)_ |
| **Буквы** | _(полный алфавит RU, листание по 4)_ |
| **ABC** | _(полный A–Z)_ |

Фрукты/овощи/дом — **не** в этой игре (нет звука в манифесте).
