# S14 — «Собери фигурку» (shape-build) — бриф

**Дата:** 24.09.2026 · **Статус:** **S14 polish код 0.15.9** (арт PNG — гибрид, по мере нарезки)

SSOT арта (черновик): **`docs/assets/shape-build-ART.md`**

## User story (цель)

Ребёнок 2–3 лет выбирает **знакомую картинку-образец** (дом, машина…), **перетаскивает** крупные **геометрические фигуры** на **своё место** в силуэте, пока картинка не «сложится»; ошибки мягкие; можно собрать **другой** образец.

## Путь ребёнка

Актуальный экран — блок **«Сейчас в коде (0.15.9)»** ниже и таблица решений викторины. Раннее описание скелета (5 текстовых кнопок, только drag) снято 24.09.2026: оно противоречило коду.

## Разрывы: идея / код / UX

| Тема | SSOT | Сейчас | Риск 2–3 года |
|---|---|---|---|
| Образцы | 5 шаблонов ✅ | Placeholder CSS | Слабая **мотивация** («что строим?») |
| Свобода | «образцы + свобода» | Только шаблон | Родитель ожидает «поиграть фигурами» — **gap** |
| Выбор шаблона | Без чтения | **Текстовые** кнопки | Нужны **иконки/миниатюры** |
| Размер | iPad landscape, крупный touch | Доска `min(42dvh, 22rem)` | **Мелко** vs пазл/sort после S14 |
| Ввод | move only | Только drag | Часть детей — **тап→тап** (как пазл) |
| Подсказка | — | Подсветка формы после ошибок | Нет **«сюда этот кусок»** как в пазле |
| Chrome | sort/puzzle: тост | Мяu + длинные тосты | Отвлекает |
| Похвала | разнообразие | 2 фразы + beep | Пул `praise.ts` / sfx |
| Magnet | щедрый | 56px, центр→центр | Промахи на планшете |
| Праздник финала | желательно | Только текст «Готово» | Слабое **завершение** |

## Рынок (паттерны toddler shape / sorter apps)

| Паттерн | Смысл | Вывод |
|---|---|---|
| Крупные формы, 3–5 деталей | Wooden puzzle / shape sorter | Наши шаблоны 3–4 слота — **ок** |
| Силуэт + цвет формы | Matching | Цвет слота = цвет фигуры ✅ (placeholder) |
| Без rotate | Toddler tangram apps | MVP ✅ |
| Щедрый snap | Меньше злости | Усилить magnet + rect hit как пазл |
| Иконки шаблонов | Без чтения | P1 |
| Опциональный «стол» | Свободная игра | Продуктовый выбор (викторина) |

## Педагогика (осторожные формулировки)

- **Форма + пространство:** «круг в круглое место» — база для 2–3 лет (с помощью взрослого).
- **Part–whole:** образец целиком vs собранный — сильнее с **иллюстрацией** шаблона (S16).
- **Не** обещаем «развивает логику» — только **игровая** практика сопоставления.

## Было → станет (если принять пакет как у пазла)

| Было | Станет | Почему лучше |
|---|---|---|
| Текстовый picker | Ряд **картинок-шаблонов** | Без чтения |
| Малая доска | Stage **на высоту** экрана | Меньше промахов |
| Только drag | Drag + **тап→tap** | 2 года |
| Hint по форме | **Target slot** + увеличение фигуры | Яснее «куда» |
| Мяu в chrome | Тост only | Фокус |
| «Готово» текстом | Короткий **celebration** (CSS/sfx) | Эмоциональное закрытие |
| Свобода 0 | **Варианты** на викторине | Закрыть gap 2.5 |

## Варианты на викторину (агент)

1. **Объём S14:** только P0–P1 (layout, picker, hints, chrome) vs + tap + celebration + sfx.
2. **Свобода:** не MVP / «стол» с лишними фигурами после сборки / отдельная вкладка «Играй».
3. **Дубликаты формы:** оставить «любой круг» vs строго **home slot** (сложнее).
4. **Имя ребёнка:** убрать с экрана игры / оставить в тосте chrome.
