## User story (зафиксировано владельцем)

«Гости у Мяu» — **не Tamagotchi**: нет голода, смерти, шкал, выигрыша/проигрыша. При входе — **реальное** время суток; **утро/вечер** — **ванная**, ритуалы (умыть, зубы, одеть/купать…); **день/ночь** — наблюдение, тост «Мяu занят» / «спит», лёгкие тапы по комнате/звёздам. Можно **вручную** переключить 🌅☀️🌆🌙 и **«Сейчас»**. На стене — **часы 24ч** (код; на PNG S16 — слот под часы).
