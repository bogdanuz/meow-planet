## 1. Лопни шарик

**Зона:** Радужная поляна · **Модуль:** 2.1 · **Статус:** ЗАФИКСИРОВАНО (механика)

**Что видит ребёнок:** **небо** с воздушными шариками (5 цветов на поле, sm/lg).
**Что делает:** тап по шарику → шарик лопается (анимация + звук, не резкий).
**Режимы:**
- **Свободно:** 8 шаров; любой тап — похвала; «Шарики ждут — выбирай любой!»
- **Задание (★):** 5 шаров; типы — цвет, оба цвета, цвет+размер, размер; фразы — `docs/assets/balloon-pop-VOICE-SCRIPT.md`.

**Soft-error:** при активном задании «чужой» шарик **не лопается** — лёгкое покачивание и
мягкая подсказка Мяу; после победы — **случайная** похвала из пула, пауза ~1,6 с, новое задание и небо.
Позиции оставшихся шаров при лопании не меняются; при обновлении неба — новая перестановка слотов.
**Свободно:** 8 шаров, случайно по зонам неба, охранные поля. **Задание:** 5 шаров (+25% rem).
**Задания (S14):** цвет (1 шар), оба цвета (2), цвет+размер (комбо), один большой/малый, два больших; без «все маленькие/большие».
**Реплика:** в цветовых заданиях слово цвета в тосте — **жирное и цветом шара**.
**Озвучка (ассеты):** ~39 mp3 по `docs/assets/balloon-pop-VOICE-SCRIPT.md` (воспроизведение — S16).
**Настройки родителя:** «Задания (★) в Лопни шарик»; общие — звук/тихий режим.

**S14 (23.09.2026, 0.14.9):** небо; Мяу + реплика; «Свободно»/«Задание»; фразы — voice script;
ассеты: `balloon-pop-sky`, **5** PNG шаров на поле, `meow-balloon-guide` (ASSET-MANIFEST).

## 2. Изучаем звуки с Мяу

**Зона:** Звуковая роща · **Модули:** 2.2 + 2.8 (музыка) + 2.14 (алфавит) · **Статус:** S14 **ГОТОВО** (0.15.0); PNG объектов — S16

**Что видит ребёнок:** карусель категорий (например: животные, инструменты, транспорт,
буквы РУ/EN); внутри категории — сетка крупных карточек.
**Что делает:** свайп по категориям (точки-индикаторы без цифр) → тап по карточке →
звук объекта + голос называет его.
**Важно (зафиксировано):** это **не викторина «угадай»** — просто тап→звук. Только
объекты, у которых есть естественный звук (животные, инструменты, транспорт). Буквы
РУ/EN — отдельная категория внутри этой же игры (не отдельная плитка на карте).
**Переключатель РУ/EN:** один тумблер; на EN — буква без слова-примера (только звук буквы).

**Soft-error:** отсутствует как понятие — тут нет «неправильного» тапа.
**Настройки родителя:** можно скрыть категорию EN, если рано.

🟡 **Открытые детали:** точный список категорий и объектов для MVP-релиза — черновой
список есть в банке объектов (`Планета_Мяу_Идея_продукта.md` §13, 106 объектов/14
категорий), но не все 106 объектов имеют естественный звук (например «хлеб», «мыло» —
звука не имеют). Нужно решение: какой поднабор бака объектов входит именно в звуковую
игру MVP. Предварительный кандидат — в `docs/assets/ASSET-MANIFEST.md`, раздел «Звук».

## 3. Куда положить?

**Зона:** Мастерская звёзд · **Модуль:** 2.3 · **Статус:** ЗАФИКСИРОВАНО

**Что видит ребёнок:** 2–4 корзинки/контейнера и объекты для сортировки (по цвету,
форме или категории).
**Что делает:** **и тап+тап, и drag** работают с первого дня (не только один способ) —
ребёнок либо тапает объект, затем корзинку, либо тащит объект пальцем прямо в корзинку.
**Soft-error:** объект в «неправильную» корзинку → мягко возвращается на место с лёгкой
анимацией (не «неверно!», без звукового наказания), Мяу подсказывает.
**Настройки родителя:** нет специфичных.

**S14 polish 24.09.2026:** **5 корзинок** (силуэт + цвет рамки); подписи — **Мячик, Кубик, Пирамидка, Сердечко, Звёздочка**.
В корзину — **та же форма**; цвет **1:1** с формой. Chrome без Мяu, подсказки-тосты. 10 игрушек (2×5).
Ассеты: `sort-colors-ART.md`. См. `S14-sort-colors-GAME-POLISH.md`.

## 4. Собери пазл

**Зона:** Мастерская звёзд · **Модуль:** 2.4 · **Статус:** ЗАФИКСИРОВАНО

**Что видит ребёнок:** вертикальную **галерею превью** (6 сцен + свои фото) и **доску 4:3**
с силуэтами ячеек.
**Что делает:** выбирает картинку → кладёт **4 / 6 / 9** прямоугольных кусочков (**drag**
или **тап→тап**) на фиксированные места; при выборе кусочка подсвечивается **его** ячейка.
**Своя картинка (MVP):** кнопка **+** в игре → файл с устройства (**без камеры**) →
кадрирование **4:3** → хранение локально (IndexedDB), без облака.
**Soft-error:** кусочек не подходит → не примагничивается, можно пробовать снова.
**Настройки:** число кусочков **4 / 6 / 9** — в игре за **капчей** (⚙); не в родительском центре.
**S14:** toddler **frame puzzle** (не interlock jigsaw); headbreaker — будущее. SSOT: `S14-puzzle-BRIEF.md`.

**Открытая деталь — ЗАФИКСИРОВАНО (принято предложение агента) 22.09.2026:** **6 сцен**
в галерее MVP: Мяу дома, поляна, лес, море, зима, лето. См.
`docs/assets/ASSET-MANIFEST.md` раздел «Пазл-сцены».

## 5. Собери фигурку

**Зона:** Мастерская звёзд · **Модуль:** 2.5 · **Статус:** ЗАФИКСИРОВАНО

**Что видит ребёнок:** образец-силуэт и набор фигур; **10 шаблонов** (S14 24.09: + солнце,
цветок, лодка, яблочко, звёздный зайчик к базовым пяти).
**Что делает:** перетаскивает (move) фигуры на образец, пока картинка не сложится.
**Важно (зафиксировано для MVP):** только перемещение — **без** поворота (rotate) и
масштабирования (scale) фигур, чтобы не усложнять для 2–3 лет.
**Soft-error:** фигура не на своём месте — просто не примагничивается, без ограничения
попыток.
**Настройки родителя:** нет специфичных.

*Открытых деталей нет — шаблоны и правило «без rotate/scale» уже зафиксированы.*

## 6. Прятки

**Зона:** Уголки планеты · **Модуль:** 2.6 · **Статус:** ЗАФИКСИРОВАНО (частично)

**Что видит ребёнок:** крупную сцену (например комнату) с 3–4 крупными спрятанными
объектами.
**Что делает:** Мяу просит найти конкретный объект («Найди мячик!») → тап по объекту,
когда ребёнок его заметил на сцене → объект «находится» (выпрыгивает/светится).
**Подсказки:** если долго не находит — лёгкое покачивание/подсвечивание объекта (не
обязательный таймер, подсказка появляется мягко).
**Soft-error:** тап не туда — ничего страшного не происходит, можно тапать сколько угодно.
**Настройки родителя:** нет специфичных.

**Открытая деталь — ЗАФИКСИРОВАНО владельцем 22.09.2026:** третья сцена — **пляж/море**.
Итог: комната + поляна + пляж/море (`hide-beach.png`). См.
`docs/assets/ASSET-MANIFEST.md`.

## 8. В гостях у Мяу

**Зона:** Домик Мяу на орбите · **Модули:** 2.13 (питомец) + 2.16 (ритуалы) · **Статус:** ЗАФИКСИРОВАНО

**Что видит ребёнок:** домик Мяу; **только Мяу** — без выбора других питомцев.
**Что делает по времени суток** (по умолчанию — реальное время устройства, плюс ручной
переключатель солнце/луна и кнопка «Сейчас»):

| Период | Что можно делать | Что на экране |
|---|---|---|
| Утро | Умыть, почистить зубы, одеть | Мяу проснулся, зевает |
| День | Уход недоступен | Мяу рисует/играет; лёгкие тапы по деталям фона |
| Вечер | Умыть, купать, зубы | Мяу готовится ко сну |
| Ночь | Уход недоступен | Звёзды (тап без звука), тихая музыка |

**Важно (зафиксировано):** день и ночь — **не** мёртвые заглушки «недоступно», а
отдельные спокойные сцены с наблюдением/лёгкими тапами. Реакция мгновенная: умыл →
сияет; покормил → жуёт — **без шкал, таймеров, progress-bar**.
**Soft-error:** нет понятия ошибки — это забота, не тест.
**Настройки родителя:** нет специфичных.

*Открытых деталей нет — полностью описано в паспортах §11.1 и §11.3 идеи.*

## 9. Считаем с Мяу

**Зона:** Мастерская звёзд · **Модуль:** 2.18 · **Статус:** ЗАФИКСИРОВАНО

**Что видит ребёнок:** два режима-вкладки в одной игре.
**Режим А (порядок):** тап по предметам по порядку 1→N со счётом вслух («один, два,
три…»).
**Режим Б («Дай Мяу N…»):** показывается большее количество предметов, ребёнок выбирает
нужное количество.
**Диапазон MVP:** 1–10, но **в настройках родителя** можно ограничить до 1–3.
**Soft-error:** неправильное количество в режиме Б — Мяу мягко пересчитывает вместе с
ребёнком, без «неверно».
**Настройки родителя:** лимит диапазона (1–3 или 1–10).

*Открытых деталей нет — режимы и диапазон зафиксированы в паспорте §11.4 идеи.*
