# S16 — «В гости» (meow-home) — бриф

**Статус:** **ЗАФИКСИРОВАНО 03.10.2026** — викторина владельца, 11 туров. **ГОТОВО в коде 0.21.0 (03.10.2026)** — игра открыта в меню, весь арт сгенерировал Cursor (`docs/assets/meow-home-ART.md`), фразы текстом в облачке (`docs/assets/meow-home-VOICE-SCRIPT.md`), звуки синтезом. Ждём просмотра владельцем и точечных правок, потом запись голоса.

Прошлый бриф S14: `S14-meow-home-BRIEF.md` (0.15.13), улица — `S14-seasons-BRIEF.md`.
Экран игры: `S16-GAME-SCREEN-PATTERN.md`.

## Идея владельца (03.10.2026)

Уход за персонажем — «тамагочи без смерти и голода»: почистить зубы, умыть, укрыть
одеялом, погладить, покормить и другие действия. Без наказаний, просто следить и
ухаживать. Улица с временами года — причина и следствие: персонаж без шапки и куртки
зимой мёрзнет и говорит «Мне холодно, надень шапку»; летом в куртке — жарко, надо
переодеться; дождь при солнце — радуга, при облаках — нет. Всё одинаково для кота и
совы: меняется персонаж, игра та же. Ассеты и анимации — в общем стиле хаба.

## Что было в коде до S16 (0.15.13)

- Сцена по реальным часам: утро/вечер — ванная, день — комната, ночь — спальня;
 кнопки 🌅☀️🌆🌙, «Сейчас», часы 24ч.
- Уход — кнопки-эмодзи (умыть, зубы, одеть, купать, покормить, погладить):
 звук, мигание, строчка текста. День — 3 эмодзи, ночь — звёзды и одеяло.
- Улица: панели «Сезон» / «Погода» с текстом, погода — одна из списка; дождевик и
 куртка в снег — сами, иначе куртка тапом по Мяу; радуга — дождь, потом солнце;
 снеговик с морковкой, листья, цветок. Только Мяу, CSS-заготовки, без голоса.
- В меню «В гости» открывает заглушку «скоро».

## Тур 6 — причина и следствие на улице (ЗАФИКСИРОВАНО 03.10.2026)

Ощущение тепла = сезон + погода: зима — всегда холодно; осень — прохладно, в ветер
холоднее; весна — тепло; лето с солнцем — жарко, лето с тучами — тепло.

| ID | Решение |
|---|---|
| mh6_clothes | Все: **холодно** без шапки/куртки — дрожит, «Брр, холодно! Надень шапку!» (в облачке — первая недостающая вещь); **жарко** в куртке — обмахивается, «Ух, жарко! Сними куртку!», хочет панамку; **дождь** без зонта/дождевика — мокнет, «Ой, я мокну! Дай зонтик!»; **холодный ветер** без шарфа — ёжится, «Дай шарфик!»; **одет правильно** — «Тепло!», «Хорошо!» |
| mh6_nature | Все: **радуга** (солнце + дождь; тучи + дождь — нет); **цветы** раскрываются на солнце, закрываются при тучах, пьют в дождь; **лужи** после дождя, летом и осенью **грибы**; **снеговик тает** весной/летом (лужа + морковка), **сосульки** капают; **ветер** — листья, вертушка, бельё на верёвке, воздушный змей |
| mh6_play | Все: **лужи** (в сапогах весело, без — грязные лапки); зима — **снеговик** в 3 тапа + морковка, **санки** с горки; осень — **куча листьев**; весна — **кораблик** в ручейке; лето — **песочница**, **лейка**, **мороженое** тает на солнце; **качели** в любой сезон |
| mh6_animals | Все: весна — **птички**; лето — **бабочки**; после дождя — **улитка**; осень — **белка** с орешком; зима — **снегирь**. Тап — реагируют |
| mh6_home | Все: без сапог в лужу/песочницу → дома **грязные лапки**; с холодной улицы → дома **дрожит** → тёплое питьё; **промок** без зонта → дома полотенце; после долгой прогулки → **хочет кушать** |
