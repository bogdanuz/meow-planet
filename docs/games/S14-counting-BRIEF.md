## Педагогика (консервативно, не медицинский claim)

Для **2–3 лет** в продукте: счёт **вместе со взрослым**, короткие сессии, лимит **1–3** по умолчанию в настройках. Конкретные предметы (яблоко, звезда…) поддерживают **поочерёдный** тап «один-в-один», а не абстрактные точки. Мы **не** заявляем «учим арифметике по WHO» — только механика hub + co-play prompt в copy.

## User story

Ребёнок с Мяу **считает предметы**: по порядку 1→N или набирает **N штук** в режиме «Дай Мяу». Можно сменить **чем считаем** (🍎 ⭐ 🐟).
