## Приоритеты (что делаем раньше)

1. **P0 — хаб и навигация** (ребёнок и родитель каждый день): welcome, menu, свайп назад, иконки chrome.  
2. **P1 — offline / первый запуск** (ваша история про iPad и кэш): splash + precache.  
3. **P2 — быстрые правки по играм** (низкий риск): alphabet, puzzle gallery/scale, hide-seek подписи.  
4. **P3 — sound-world инструменты** (средний объём, новые экраны-tap zones).  
5. **P4 — seasons** (большая смена механики + layout + тосты + радуга).  
6. **P5 — counting** (переработка UX + убрать маскота с экрана).  
7. **P6 — shape-build / meow-home / sort / balloon** — в основном **промпты + мелкий layout** после ассетов.  
8. **P7 — родительский центр** (структура, тексты, evidence).  
9. **S15 — мегафайл + брендбук + слияние voice/ART/manifest → archive**.

### P15-07 — Изучаем звуки (sound-world)

| Блок | Поведение |
|------|-----------|
| Животные/транспорт/предметы | Как сейчас: тап → звук; промпты карточек в едином стиле |
| **Инструменты** | Тап по категории → **экран инструмента** (не один mp3) |
| Барабаны | Одна картинка установки; **N зон** → разные звуки (описать N и типы ударов) |
| Бубен | Большой бубен, звук как сейчас + **лёгкая wobble-анимация** |
| Маракасы | 2 маракasa, отдельные tap + shake |
| Колокольчик | Tap/drag → звон + покачивание |
| Пианино | **7 клавиш** (до–си); статичный корпус + 7 hit areas **или** 7 отдельных спрайтов клавиш |
| Гитара | 6 струн, tap → звук + вибрация струны |
| Алфавит RU/EN | **Последняя строка по центру** (не влево) |

**Процесс ассетов:** промпт → вы генерируете → агент разметит **hotspots** по финальному PNG.

### P15-09 — Времена года (seasons) — **крупный спринт**

**Концепция (из запроса владельца):**

- Одна локация: **детская площадка во дворе** (МКД, качели и т.д.).
- **4 сезона** = одна композиция, меняется art/слой (лето → референс для осень/зима/весна).
- **Мяu + одежда:** смена сезона без автосмены одежды → тост «Мяu холодно / жарко» → ребёнок надевает/снимает куртку.
- **Погода:** панель слева (дождь, снег, солнце, облачно…); сезоны — отдельная подписанная панель.
- **Радуга:** только если был дождь и включили солнце (+ короткий текст для родителя).
- FX: дождь/снег/листья — **CSS/code vs спрайты** — варианты в викторине; ссылки на готовые эффекты из research (`docs/09-VISUAL-DESIGN-RESEARCH.md` и идея продукта).
- Зимой опционально **снеговик** + морковка (интерактив).

**До кода:** согласовать scope с текущим sandbox-only S14 (`S14-seasons-BRIEF.md` будет supersede).

## Решения P15-V1 (владелец)

| Тема | Решение |
|------|---------|
| Порядок работ | **Строго по дорожной карте** P15-01 → … → P15-12; без перескоков |
| Фон игр | **Локации/сцены** — уникальные; **задний «подложечный» слой** экрана — **один стиль везде** |
| Splash | **Анимация + %** до **полного precache** (PWA) |
| Меню | **8** art-плиток с названием на картинке + **отдельный** CTA «В гости к Мяu» |
| Seasons | **Один спринт P15-09** (двор-площадка, одежда, тосты, радуга, панели) |
| Counting | **Маскот убрать** с экрана |
| Родители / капча | **Капча при каждом входе** в настройки; **внутри** экрана настроек **не** оставлять текст/остатки капчи на UI |
| MEGAFILE + брендбук | **После** завершения P15 |
| Свайп назад | **Расширить** зону с края + **подсказка для родителя** (без кнопки «Назад» для ребёнка) |
