# Спринты разработки MVP

**Дата активации:** 22 сентября 2026  
**Статус:** ЗАФИКСИРОВАНО — порядок разработки утверждён запросом владельца  
**Источники:** `Планета_Мяу_Идея_продукта.md`,
`docs/games/MVP-GAMES-DETAILED.md`, `docs/06-ROADMAP.md`.

## Правила выполнения

- `[ ]` не начато, `[~]` в работе, `[x]` готово, `[!]` заблокировано.
- Одновременно выполняется только один спринт.
- Каждая задача должна оставлять приложение запускаемым.
- Новая логика сопровождается unit-тестом; критический пользовательский путь — e2e.
- Перед завершением спринта: `npm run typecheck`, `npm run test`, `npm run build`,
  релевантные e2e-тесты (**локально** — только если K-004 закрыт; иначе явно
  написать, что e2e проверил CI, и не закрывать M1).
- В конце спринта обновляются `05-CURRENT-STATE.md`, `CHANGELOG.md`, а при решении —
  `04-DECISION-REGISTER.md`.
- Финальные ассеты до S13 не блокируют разработку: используются CSS/SVG-заглушки.
- **Просмотр в браузере:** когда есть что смотреть (меню/карта/игра), агент сам
  запускает `npm run dev` и даёт владельцу ссылку — см. `docs/06-ROADMAP.md`
  «Локальный просмотр и тесты».
- **Отдельный тестовый стенд с UI** — не строить заранее; только по явной просьбе
  владельца (см. тот же раздел дорожной карты).
