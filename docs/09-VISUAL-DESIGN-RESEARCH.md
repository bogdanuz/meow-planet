# Визуальный стиль — исследование для детей 2–3 лет

**Статус:** **ЗАФИКСИРОВАНО** — выбран стиль **A (книжная иллюстрация)**, 21.09.2026.  
**Дата:** 21 сентября 2026  
**Контекст:** PWA на iPad, хаб «Планета Мяу», без рекламы и агрессивной геймификации.

---

## 1. Зачем отдельный документ

В4 (custom): стиль выбираем **не «как нравится взрослому»**, а по сочетанию:

- узнаваемости и спокойствия для ребёнка 2–3 лет;
- крупных зон касания и минимума «шума» на экране;
- рекомендаций по медиа и раннему обучению (AAP, исследования UX для детей).

После просмотра примеров — отдельная AskQuestion-викторина по вариантам A–Г из §20 идеи (или свой вариант).

---

## 2. Краткие выводы для «Планеты Мяу»

| Принцип | Практика в продукте |
|---|---|
| Мало текста | Управление без чтения; подписи опционально для взрослого |
| Крупные цели | Тап-зоны «почти на весь объект»; drag — запас по краям |
| Спокойный фон | Не мигать без цели; анимации **по смыслу** (подсказка, успех) |
| Без отвлечений | Нет рекламы, pop-up, «сюрприз-игр» вне сюжета |
| Звук + картинка вместе | Голос/звук предмета при тапе — как «congruent hotspot» |
| Тихий режим | См. В2.1: музыка + приглушение ярких праздничных реакций |
| Совместность | AAP: для 2–3 лет полезнее игра/просмотр **со взрослым** (у нас — без отдельного режима, но iPad на столе) |

## 3. Источники (ссылки)

### Медиа и качество контента

- [AAP: выбор приложений для малышей](https://www.aap.org/en/patient-care/media-and-children/center-of-excellence-on-social-media-and-youth-mental-health/qa-portal/qa-portal-library/qa-portal-library-questions/preferred-method-of-screen-time/) — co-viewing, избегать рекламы и «псевдо-образовательных» приложений.
- [Common Sense Media — reviews детских приложений](https://www.commonsensemedia.org/app-reviews) — независимые обзоры (удобно перед выбором референсов).
- [PBS KIDS](https://pbskids.org/apps/) — эталон «спокойного» образовательного бренда для дошкольников. мне очень нравится

### UX / тач для детей

- [TIDRC — framework рекомендаций по touchscreen для детей (PDF)](https://stirlab.org/wp-content/uploads/A-Framework-of-Touchscreen-Interaction-Design-Recommendations-for-Children-TIDRC-Characterizing-the-Gap-between-Research-Evidence-and-Design-Practice.pdf)
- Альтернатива: поиск «TIDRC touchscreen children design recommendations» — синтез HCI-гайдов (крупность, визуальность, когнитивная нагрузка).

### Hotspots и анимация

- [Word learning in storybook apps (RRQ)](https://doi.org/10.1002/rrq.556) — **congruent** (по сюжету) hotspots помогают; лишние игры в кадре отвлекают.
- [Haptics and hotspots study (UvA, 4–5 лет)](https://pure.uva.nl/ws/files/109603573/Haptics_and_hotspots_creating_usable_and_educational_apps_for_children_in_the_Netherlands.pdf) — salient hotspots и простые жесты (tap vs drag) влияют на удобство.

### WCAG / доступность (крупность, контраст)

- [WCAG 2.2 — Understanding Target Size](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html) — ориентир ≥24×24 CSS px; для 2–3 лет в продукте целим **значительно крупнее**.

## 4. Варианты стиля (для будущей викторины В4)

Сравнение с **публичными референсами** (не копировать ассеты — только направление).

### A. Книжная иллюстрация - очень нравится - выбираю этот стиль для своего хаба!

- **Ощущение:** тёплая детская книга, мягкие контуры, «акварель/гуашь».
- **Примеры брендов:** [StoryToys](https://storytoys.com/) (интерактивные книги), часть линейки [Sago Mini](https://sagomini.com/) (иллюстративный flat).
- **Плюсы для 2–3 лет:** узнаваемые объекты, мало «пластика», спокойные сцены.
- **Риски:** нужна дисциплина — не перегружать деталями фона.

### B. Аппликация / бумага нормально

- **Ощущение:** вырезанная бумага, текстуры крафт, простые формы.
- **Примеры:** ранние [Lingo Kids](https://lingokids.com/) экраны (бумажный collage), [Highlights](https://www.highlights.com/) digital activities aesthetic.
- **Плюсы:** тактильность «руками», хорошо для сортировки/конструктора.
- **Риски:** при плохом контрасте «бумага на бумаге» — объект теряется.

### C. Мягкий объём («пластилин»)

- **Ощущение:** 3D-clay, округлые формы, мягкий свет.
- **Примеры:** [Nosy Crow](https://nosycrow.com/) apps (часть 3D), clay-style indie на [App Store Kids](https://apps.apple.com/us/genre/ios-kids/id36?ageBand=17500) (фильтр 2–4).
- **Плюсы:** «милая» физичность, хорошо для персонажей.
- **Риски:** тяжелее единый стиль на все 12+ механик; дороже в производстве.

### D. Гибрид 2D + лёгкий рельеф

- **Ощущение:** flat-иллюстрация + мягкая тень/parallax без полноценного 3D.
- **Примеры:** [Toca Boca](https://tocaboca.com/) (упрощённый объём), [Sago Mini World](https://sagomini.com/world/) (слои с глубиной).
- **Плюсы:** баланс «читаемость на iPad» + «живость»; хорошо масштабируется на игры.
- **Риски:** нужен единый lighting guide, иначе «зоопарк стилей».

## 5. Чек-лист «понравится ребёнку» (наблюдение с вашим ребёнком)

После просмотра 2–3 референс-приложений (по 5–10 мин каждое):

1. Ребёнок **сам тянется** тапать или ждёт подсказки?
2. Не отвлекается ли на мелкие движущиеся элементы фона?
3. Узнаёт ли объект с первого взгляда (силуэт + цвет)?
4. Не пугает ли громкий/резкий звук успеха?
5. Может ли повторить жест после одной демонстрации Мяу?

Запишите 1–2 наблюдения — они пойдут в финальную викторину.
