**Статус текста:** ЗАФИКСИРОВАНО (логика) 01.10.2026 по викторине · **озвучка:** в игре с 01.10.2026, 158 файлов (отчёт — [sort-colors-VOICE-CUT-REPORT.md](sort-colors-VOICE-CUT-REPORT.md)).  
**Источник строк в коде:** `src/games/sort-colors/phrases.ts`. Unit-тест сверяет этот файл с кодом строка в строку.  
**Папка mp3:** `public/assets/games/sort-colors/voice/`. Имена файлов не менять без правки кода.

## Как записать

1. ElevenLabs, тот же голос, что в «Лопни шарик». Спокойный темп сказки, без шёпота и без «строгого учителя».
2. Один длинный трек: все фразы **сверху вниз в этом порядке**, между фразами пауза ~1 секунда (в тексте для генерации ставьте пустую строку или `<break time="1s"/>`).
3. Можно частями (например, по разделам) — тогда имена `sort-colors-voice-reel-1.mp3`, `-2.mp3`… в том же порядке.
4. Положите в `assets-master/games/sort-colors/sort-colors-voice-reel.mp3` и напишите «готово озвучка». Cursor нарежет: `node scripts/split-sort-colors-voice.mjs`.

**Как режет скрипт (ЗАФИКСИРОВАНО 01.10.2026, AskQuestion):** тишина −40 dB от 0,25 с; ровно 157 разрезов, выбранных по тексту — длина каждого куска должна совпасть с ожидаемой по числу букв, внутри кусков остаются паузы покороче. «157 самых длинных пауз» (`--longest`) не подошло: паузы между фразами (от 0,51 с) и внутри «Это мячик. | Ему нужен…» (до 0,59 с) пересекаются. По краям 60/90 мс тишины, одинаковая громкость, mp3 моно. Сначала режет во временную папку; в игру кладёт, только если 158 файлов, нет кусков короче 0,3 с, одно слово ≤ 2 с, двухсоставные ≥ 1,5 с и нет сбоя темпа. Иначе печатает таблицу и останавливается.

Имя ребёнка в голос не идёт: в тексте на экране оно подставляется перед заданием, а звучит та же фраза.
