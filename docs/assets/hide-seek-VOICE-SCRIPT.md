**Статус текста:** ЗАФИКСИРОВАНО 03.10.2026 — итоговый список владельца, 150 фраз (было 185: убраны `find-*`, на предмет 2 фразы; общие фразы переписаны, добавлены `start`, `next`, `praise`, `idle`; «грибок» → «грибочек»).  
**Озвучка:** записана владельцем одним треком `assets-master/games/hide-seek/hide-seek-voice-reel.mp3`, нарезка — `node scripts/split-hide-seek-voice.mjs` (тот же способ, что в «Куда положить?»).  
**Источник строк в коде:** `src/games/hide-seek/phrases.ts` (`HIDE_SEEK_VOICE_SCRIPT`). Unit-тест сверяет этот файл с кодом строка в строку.  
**Папка mp3:** `public/assets/games/hide-seek/voice/`. Имена файлов не менять без правки кода.

Порядок сверху вниз = порядок в треке (n-й кусок = n-й файл).

## Где звучит в игре

| Группа | Когда |
|---|---|
| `intro-*` | Вход в сцену из галереи или «Ещё» |
| `start-*` | «Заново» — новый раунд на той же сцене |
| `where-*` | Задание («Где спряталась уточка?»), повтор через 6 с, кнопка «Подсказка» |
| `found-*` | Нашёл предмет |
| `praise-*` / `next-*` | Сразу после «Вот он…!», случайно одна из двух групп; после последнего предмета — только похвала |
| `idle-*` | 12 с без касаний — вместе с мягким сиянием (если «Подсказки сами» включены) |
| `near-*` | После двух промахов подряд |
| `other-*` | Нашёл другой предмет раунда |
| `done-*` | Все нашлись |

Варианты внутри группы выбираются случайно, один и тот же два раза подряд не звучит.
