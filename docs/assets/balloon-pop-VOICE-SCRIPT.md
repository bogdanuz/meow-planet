- Один голос Мяу на всю игру; темп спокойный, как сказка.

- Короткие паузы после «!» и «.»; без шёпота и без «строгого учителя».

- Экспорт: **mp3**, моно, ~48 kHz или 44.1 kHz; без музыки на дорожке.



Файлы лежат в `public/assets/games/balloon-pop/voice/`. Мастер-трек: `assets-master/games/balloon-pop/balloon-pop-voice-reel.mp3`. Нарезка: `node scripts/split-balloon-pop-voice.mjs`.
