# Как мы работаем

**Вы делаете** — рисуете или выбираете файл.  
**Cursor делает** — проверяет файл, кладёт копию в приложение, подключает, показывает экран.  
**Результат** — что должно появиться.  
**Проверка** — как понять, что правильно.  
**Подтверждение** — Cursor останавливается и ждёт вас.

Оригинал высокого качества — `assets-master/`. В игру — уменьшенная копия в `public/assets/`.

## После добавления любого runtime-файла

1. Копия для приложения должна находиться в `public/` либо импортироваться из `src/`.
   Оригиналы в `assets-master/` в приложение и precache не входят.
   Runtime-файл больше 64 МиБ считается ошибочно положенным мастером и блокирует build.
2. Не добавлять ассет в ручной boot-список: единственный список создаёт Workbox.
3. Не ограничивать precache перечнем расширений — действует `globPatterns: ['**/*']`.
4. Выполнить:

```bash
npm run typecheck
npm run test
npm run build
npm run test:e2e:boot
```

Для UI/игры дополнительно:

```bash
npm run test:e2e -- --project=chromium
```

`npm run build` должен подтвердить равенство Workbox manifest, progress manifest и
всех app-файлов `dist`. Полная политика:
`docs/quality/PWA-OFFLINE-GUARDRAILS.md`.
