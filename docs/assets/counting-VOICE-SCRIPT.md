Порядок сверху вниз = порядок в треке (n-й кусок = n-й файл).

## Как записывать

1. Читать строки подряд сверху вниз, **между фразами пауза 1 секунда** (внутри фразы — короткие паузы, как обычно говорите).
2. Ошиблись — не останавливаться: сделайте паузу 3 секунды и прочитайте **эту же строку** заново, потом скажите агенту номер строки — лишний кусок уберём.
3. Голос тёплый, спокойный, как будто сидите рядом с ребёнком на ковре. Числа — чётко, без спешки.
4. Пока голоса нет, в игре фразы показываются только текстом в облачке у ведущего.

## Где звучит в игре

| Группа | Когда |
|---|---|
| Цифры (панель внизу) | Нажали на цифру |
| Сколько в ящике | Положили / достали игрушку, пересчёт ящика, конец счёта по одной |
| Начало свободной игры | Вход в игру, «Свободно», «Заново» |
| Сменили игрушки | Выбрали другие игрушки кнопкой «Игрушки» |
| Все в ящике | Сложили в ящик все игрушки с коврика — праздник |
| Было — стало (больше) | Задание «Добавь одну» выполнено |
| Было — стало (меньше) | Достали одну из ящика; задание «Убери одну» выполнено |
| Пусто | Достали последнюю / нажали на пустой ящик |
| Начало заданий | Нажали «Задание» |
| Положи в ящик N | Задание «Положи» |
| Посчитай по одной | Задание «Посчитай» — нажимать на каждую игрушку |
| Добавь одну | Задание «Добавь» (в ящике уже лежат игрушки) |
| Убери одну | Задание «Убери» |
| Сколько? — нажми на цифру | Задание «Сколько» (цифра на ящике спрятана) |
| Где больше? | Задание «Где больше» (два ящика) |
| Мягкие ответы | Правильный ящик; положили больше; убрали больше |
| Давай вместе | Ошибка — ведущий пересчитывает вместе с ребёнком |
| Похвала | Задание выполнено |
| Дальше | Переход к следующему заданию |

Варианты внутри групп «Пусто», «Давай вместе», «Похвала», «Дальше» выбираются случайно, один и тот же два раза подряд не звучит.
