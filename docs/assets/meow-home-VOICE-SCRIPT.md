# «В гости» — фразы для озвучки

**Статус (0.21.0, 03.10.2026):** фразы звучат **текстом в облачке**, mp3 ещё нет.
Код — `src/games/meow-home/phrases.ts`; unit-тест `src/games/meow-home/phrases.test.ts` сверяет этот файл с кодом.

Как записывать (бриф, тур 8): сначала владелец смотрит игру с текстом и правит фразы, потом записывает
**два трека** — `assets-master/games/meow-home/meow-home-voice-meow.mp3` (голос Мяу) и
`meow-home-voice-olli.mp3` (голос Олли), строки по порядку таблицы, пауза ~1 с между фразами.
Cursor режет по тексту (как `split-counting-voice.mjs`) в `public/assets/games/meow-home/voice/<who>-<ключ>.mp3`.

Кот и сова говорят одно и то же, кроме слов про тело (зубки/клювик, лапки/крылышки, шёрстка/пёрышки)
и мурлыканья. Где колонка «Олли» пустая — фраза та же, что у Мяу.
