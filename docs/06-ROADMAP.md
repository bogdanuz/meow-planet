- Здесь — крупные этапы и порядок.
- В `07-SPRINTS.md` — мелкие задачи, критерии готовности и проверки.
- Спринт = один законченный проверяемый результат.
- Новый спринт после зелёных тестов и просмотра владельцем.
- Коммиты и push — только владелец через GitHub Desktop.

## Принципы порядка

1. Сначала фундамент и навигация, затем общие механики.
2. Игры делаются на простых фигурах и заглушках — **путь А**.
3. Каждая игра сначала получает логику и тесты, не финальные иллюстрации.
4. **После M3:** сначала новое меню (плитки + приветствие), затем проход по каждой
   игре с владельцем, и **только потом** мегафайл ассетов.
5. Финальные изображения подключаются только после утверждения мегафайла.
6. Устаревшие файлы при мегафайле → `archive/` + `.gitignore` (не удалять).
