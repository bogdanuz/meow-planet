# Продуктовые ограничения MVP (SSOT)

**Статус:** ЗАФИКСИРОВАНО (идея 1.0 + реестр решений).  
**Не дублировать** полный текст в rules/skills — ссылаться на этот файл.

## Аудитория и устройство

- Дети **2–3 года**; основной сценарий — **iPad landscape**, touch, без чтения для ребёнка.
- Одна очевидная задача на экран; крупные цели (**56–64 CSS px** для детских действий, с запасом между соседними целями; главный CTA может быть крупнее).

## Запрещено в MVP

- Backend, аккаунты, email, облачный sync, Google Sheets, экспорт/импорт прогресса
- Аналитика, реклама, камера, микрофона, геолокация
- Очки, звёзды, валюта, streak, leaderboard, «проигрыш»
- Таймеры, жизни, штрафы, красные кресты, грустный/наказующий маскот
- Сравнение результатов детей между собой

## Обязательно

- **Soft-error цепочка:** нейтральная реакция → мягкий намёк → демонстрация → помощь взрослого (см. идею §)
- Похвала универсальная, без ранжирования ребёнка
- Цвет **не** единственный канал информации; учитывать `prefers-reduced-motion`
- Имя ребёнка — только localStorage; в DOM только безопасный текст (не `innerHTML` с пользовательским вводом)

## Архитектура (кратко)

- Игры изолированы в `src/games/<id>/`; общее — только `src/shared/` (см. `docs/architecture/ARCHITECTURE.md`)
- Без speculative adapters/factories «на будущее» без второго реального потребителя
