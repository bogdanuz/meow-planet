## Критично

Отдельных пунктов уровня «игра не проходится / утечка данных» в трёх аудитах нет.  
Ближе всего к срочному, но по шкале аудита это **среднее**:

- версия 0.13.8 на родительском экране при пакете 0.15.22 (CR-01);
- возможный сбой, если уйти из «Звуков», пока догружается список файлов (CR-02).

Их чинить в первой пачке этапа 5, если владелец примет «среднее».

## Средне

| Проблема | Решение | Что увидит семья |
|---|---|---|
| Родительский экран показывает 0.13.8 | Записать в `APP_VERSION` ту же версию, что в `package.json` | Номер совпадёт с тем, что в обновлениях |
| Быстрый выход из «Изучаем звуки» может задеть уже закрытый экран | Не обновлять сетку после `unmount` | Уход из игры спокойный |
| В конце задания шариков второй верный хлопок может сменить задание дважды | После победы не принимать новую «победу», пока не начнётся следующее задание | Одно задание — один переход |
| «Дай N» в счёте не подсказывает ступеньками | Та же мягкая цепочка, что у режима «по порядку», без слова «неправильно» | После нескольких лишних тапов подсветится, сколько нужно |
| Одинаковая форма разного цвета в «Собери фигурку» может встать не на свой цвет | Либо snap ещё и по цвету слота, либо оставить как есть — см. вопрос ниже | Картинка собирается узнаваемо |
| Вкладки и буквы в «Звуках», кнопки режимов шариков меньше 56px | Поднять минимум и зазор | Реже промах пальцем |
| Задание счёта только фразой | Крупная цифра и столько же картинок; фраза короче | Можно играть без чтения |
| Fredoka с Google; иконка PWA — svg | Это уже S16: файл шрифта в проекте, PNG 192/512 по `PWA-APP-ICON.md` | Офлайн и иконка на экране «Домой» |
| Пачка `HEAD`-запросов при входе в звуки | Список файлов без опроса каждого адреса | Быстрее вход, ровнее офлайн |
| headbreaker и konva в сборке, игра их не показывает | Удалить мёртвый путь после подтверждения, что режим «пазл с выступами» в MVP не возвращается | Легче скачивание |

## Некритично / полировка

- Снимать все коротких таймеры и доигрывающие звуки в `unmount` (шарики, сортировка, пазл, фигурка, прятки, дом).
- Закрывать окно кадрирования пазла при выходе из игры.
- Общие куски палитры и «магнита» слота вынести в `src/shared/`, чтобы игры не импортировали друг друга.
- Удалить неиспользуемую заглушку `createStubGame`, когда будет подтверждение.
- `orientation: landscape` в манифесте, ворота «Поверни планшет» оставить.
- Подсказка, если localStorage не записал настройки.
- Убрать устаревший верх `S14-shape-build-BRIEF.md` и шапку версии в `S14-GAMES-INDEX.md` (0.15.14 → фактический пакет).
- Кнопка удаления своего фото пазла — только по желанию.

## Дизайн-система

Зафиксировать в токенах `src/styles/global.css` (не копировать числа по играм):

| Токен | Смысл |
|---|---|
| уже есть `--bg`, `--text`, `--accent`, `--font-ui`, `--font-display` | Не плодить вторую палитру в CSS игр |
| минимум детской цели **56px** | Вкладки звуков и режимы шариков подтянуть к `.touch-btn` |
| обводка выбранного / подсказанного как у `.is-soft-highlight` | Один приём «смотри сюда» |
| зазор между целями не меньше 8px, на планшете щедрее | Особенно ряды вкладок |
| без emoji как финального героя | Замена на арт S16, не новые эмодзи |

Правила проекта не переписывать: они уже ссылаются на `PRODUCT_CONSTRAINTS.md`.

## Тексты

Менять только после согласия на этот раздел.

| Место | Новый текст |
|---|---|
| Сезоны, тост холода | «Холодно. Тапни Мяу.» |
| Сезоны, тост жары | «Жарко. Тапни Мяу.» |
| Дом, полоска утра / дня / вечера / ночи | «Утро» / «День» / «Вечер» / «Ночь» |
| Счёт, миссия порядка | «Один.» (и дальше слово числа без длинной фразы) |
| Счёт, «дай N» | «Три яблока.» (число + предмет, без «Выбери») |
| Счёт, лишнее | «Давай вместе: три.» |
| Родители, шарики | «Замечает цвет и попадает по шарику.» |
| Родители, сортировка | «Класть предмет к такой же форме.» |
| Родители, пазл | «Собирает картинку из крупных частей.» |
| Родители, прятки | «Ищет знакомый предмет на сцене.» |
| Родители, звуки | К текущему абзацу: «Английские буквы отключаются в настройках.» |
| Сброс настроек | Рядом пояснение: «Имя и переключатели вернутся к начальным.» |

«Отлично!», капча, «Сохранено на этом устройстве.», «Поверни планшет» — не трогать.

4. Надписи «Добро пожаловать!» и «Выбери игру!» убрать с детских экранов или оставить мелким текстом для взрослого?
5. Мяу на играх: как сейчас (в одних играх на сцене, в других только тост) или один общий приём после арта S16?
6. Этот ремонт делать сейчас, до картинок S16, или только то, что не зависит от арта (версия, гонки, размеры кнопок, тексты)?
