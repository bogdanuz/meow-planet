# Этап 2. UX/UI-аудит для детей 2–3 лет

**Дата:** 24 сентября 2026  
**Приоритет правил:** `docs/product/PRODUCT_CONSTRAINTS.md` и `.cursor/rules/toddler-interaction.mdc` выше внешних трендов. Ориентир качества внутри проекта: skill `ux-ui-kids-hub` (книжная иллюстрация, один фокус, цели 56–64 CSS px, landscape).  
**Код не менялся.** Живой проход по экранам в браузере на этом этапе не делался: выводы — из вёрстки и текстов в `src/`.

## Ориентир 2025–2026 (не подменяет правила проекта)

По открытым обзорам этого периода (NN/g про моторику детей; обзоры toddler UX 2025–2026; этичные детские приложения вроде заметок Little Wheels):

- Крупные зоны: платформенные 44px малышам мало. NN/g для маленьких детей говорит примерно о **2×2 см**. Внутренний порог Планеты Мяу **56–64px** — консервативный минимум, его и держим. «180pt на всё» из отдельных приложений в проект не переносим: это сломает сетку алфавита и меню.
- Один жест: тап и крупное перетаскивание. Двойной тап и щипок — не для 2 лет. В пазле и фигурке уже есть и drag, и тап→тап — это совпадает с рекомендацией давать оба способа.
- Обратная связь сразу: картинка + короткий звук, без «ошибки» и без таймера-угрозы. Цепочка soft-error проекта этому соответствует.
- Книжная иллюстрация, мало текста на детском слое, персонаж как проводник, а не как судья.
- Тихий режим и `prefers-reduced-motion` — часть заботы, не «настройка для галочки».

## Как ощущается хаб сейчас

Общие токены в `src/styles/global.css`: фон `#f7fbff`, текст `#1a2a33`, акцент `#7eb8da`, шрифт Fredoka (с Google, запасной — системный). Кнопки `.touch-btn` — минимум 56×56 (`shell.css`). Ворота ориентации закрывают книжный режим текстом «Поверни планшет». Навигация: welcome → меню плиток → игра; назад/домой в chrome; родительский центр за капчей. Это совпадает с задумкой хаба.

Книжный стиль **ещё не общий**: игры на CSS-фигурах и emoji-иконках (сезоны, дом, счёт). Skill `ux-ui-kids-hub` прямо считает emoji «вместо персонажа» слабым местом до арта S16. Это ожидаемый долг стадии, не случайный разнобой цветов.

## Тренды 2026 и рекомендации

Что стоит перенести, не ломая правила проекта:

1. **Обводка цели 4px**, не тень «как у взрослого сайта». Уже есть у `.is-soft-highlight` (акцент + ореол). Имеет смысл сделать ту же обводку у «выбранной» фигуры пазла/фигурки, чтобы выбор был виден без чтения.
2. **Зазор между соседними целями ≥8–12px**, лучше больше. Вкладки «Звуков» сейчас с `gap: 0.35rem` — мало. Поднять gap вместе с min-size.
3. **Шрифт один, локальный, округлый.** Fredoka уже выбран в брендбуке. Не добавлять второй display-шрифт. Self-host — часть офлайна, не «модный шрифт 2026».
4. **Мгновенный отклик тапа** (сжатие 0.96 и короткий звук) уже есть на вкладках звуков. Повторить на корзинках и сезонах, если там отклик тише.
5. **Не добавлять** звёзды, серии дней, таймер сессии, конфетти на весь экран. Это расходится и с трендом «без давления», и с `PRODUCT_CONSTRAINTS.md`.

Что не переносить: гигантские 180px-кнопки на все контролы, озвучку каждого слова интерфейса как обязательный TTS, отдельный «режим 4–5 лет» со счётом очков.
