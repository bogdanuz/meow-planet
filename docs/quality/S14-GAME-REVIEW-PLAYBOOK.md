# S14 — проход по игре с владельцем (playbook)

**Статус: ЗАФИКСИРОВАНО** 23.09.2026 — процесс прохода 9 игр. **S14 закрыт 24.09.2026 (0.15.14).**  
**Индекс игр и версий:** `docs/games/S14-GAMES-INDEX.md`.

## Зачем

Владелец не программист: сначала **понятная картинка «как будет»**, потом код.  
Агент **не** начинает большие правки механики/UI до викторины и записи решений.

## Порядок (каждая игра)

1. **Прочитать SSOT:** `Планета_Мяу_Идея_продукта.md` (паспорт модуля), `docs/games/MVP-GAMES-DETAILED.md`, `docs/11-MVP-GAMES-MECHANICS.md`, `docs/product/PRODUCT_CONSTRAINTS.md`.
2. **Код как есть:** `src/games/<id>/`, e2e/unit, настройки родителя.
3. **Разрывы:** таблица «в идее / в коде / не хватает» + **рынок** (2–4 паттерна детских app 2–3 лет: крупный тап, без наказаний, звук после жеста — без выдуманных «исследований»).
4. **User story** (1–2 предложения) + **путь ребёнка** (5–7 шагов, простой язык).
5. **Предложения** агента: 2–4 варианта на спорный пункт; плюсы/минусы одной строкой.
6. **Викторина:** только **AskQuestion** (`.cursor/rules/interactive-quizzes.mdc`):
   - в каждом вопросе вариант **«Свой вариант (напишу в чат)»**;
   - **multi-select**, где можно совместить несколько улучшений;
   - 1 логический блок за тур (не смешивать несвязанные игры);
   - простые формулировки, пример «как на экране».
7. **Фиксация:** ответы → `docs/04-DECISION-REGISTER.md`, блок игры в `Планета_Мяу_Идея_продукта.md` (ЗАФИКСИРОВАНО), черновик `docs/games/S14-<game>-BRIEF.md`, при фразах/звуке — манифест/voice script.
8. **Код + тесты** — skill `testing-and-verification`; docs — skill `docs-sync`.

## Шаблон брифа игры

Файл: `docs/games/S14-<game-id>-BRIEF.md`

- Статус: ЧЕРНОВИК / ЗАФИКСИРОВАНО  
- User story  
- Путь ребёнка (и родителя, если есть)  
- Сейчас в коде (кратко)  
- Разрывы с идеей  
- Рынок (паттерны)  
- Варианты на викторину  
- Решения викторины (после ответов)  
- Ассеты / озвучка (если нужно)
