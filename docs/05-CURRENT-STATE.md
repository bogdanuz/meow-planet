## PWA/offline — зафиксированный инвариант

- Любой app-файл production-сборки автоматически попадает в precache независимо
  от расширения (`globPatterns: ['**/*']`).
- Ручного списка boot-ассетов нет.
- `npm run build` падает при расхождении Workbox/progress manifest или выпадении
  app-файла `dist`.
- `npm run test:e2e:boot` проверяет cold/warm/retry/error путь через `vite preview`.
- SSOT: `docs/quality/PWA-OFFLINE-GUARDRAILS.md`, ADR-0001.
