- Стек: Vite `^8.3`, TypeScript `^7.0.2`, Vitest `^4.1.11` + `jsdom`, `@playwright/test`

- Git: репозиторий связан с `https://github.com/bogdanuz/meow-planet.git`, публичный.

## 3. Важные находки, требующие решения владельца (не закрыты молча)

1. **Coverage-зависимость `@vitest/coverage-v8` установлена, но не используется** ни в
   одном npm-скрипте, ни в CI — формально «мёртвая» зависимость (нарушает правило
   AGENTS.md «без мёртвого/неподключённого кода»). Решение отложено до утверждения
   целевого % покрытия владельцем.
2. **`npm run lint` = `tsc`** — это проверка типов, а не полноценный линтер (нет проверки
   стиля/потенциальных ошибок). Настоящий ESLint не установлен. Не добавлялся в этом
   раунде, так как не был в списке подтверждённых владельцем изменений.
3. **`.cursor/rules/stack-versions.mdc` и `testing.mdc` не созданы** — было предложено в
   Фазе 0, но не входило в подтверждённый список этого раунда (владелец подтвердил только
   5 skills). Можно добавить по отдельному запросу.

## 3.1 Попытка добавить ESLint — заблокирована реальной несовместимостью (проверено, не предположение)

По решению владельца (В6) была предпринята попытка добавить `eslint` + `typescript-eslint`
взамен псевдо-линтера. Установка прошла (`--legacy-peer-deps`), но реальный запуск
`npx eslint .` завершился фатальной ошибкой: **`typescript-eslint` явно отказывается
работать с TypeScript 7.0** (в проекте `^7.0.2`), заявляя поддержку только до `<6.1.0`.
Это подтверждённый библиотекой факт (см. трекинг-issue
https://github.com/typescript-eslint/typescript-eslint/issues/10940), а не догадка.

**Решение:** установка отменена (`npm uninstall`), `eslint.config.js` удалён,
`npm run lint` остаётся псевдонимом `tsc` до появления совместимой версии
`typescript-eslint` — оставлять неработающий линтер в репозитории было бы «мёртвым
кодом», что прямо запрещено `AGENTS.md`. Зафиксировано как `K-005` в
`docs/08-KNOWN-ISSUES.md`. После установки/откатки прогнаны и подтверждены зелёными:
`npm run typecheck`, `npm run test`, `npm run build`.
