## User story

Ребёнок 2–3 лет выбирает в галерее картинку (домик, машинку, рыбку). На деревянной доске-вкладыше бледные цветные контуры, рядом на столе лежат настоящие круги, квадраты и треугольники. Он берёт фигуру, сова называет её: «Треугольник!». Ребёнок кладёт её в такой же контур. Когда всё на месте, фигуры с искорками превращаются в нарисованный предмет, и он оживает: машинка уезжает и возвращается, ракета взлетает. Сова: «Ура! Получился домик!».

## Путь ребёнка

1. Меню → плитка «Собери фигурку» → **галерея**: большие карточки с нарисованными предметами, от простых (2 детали) к сложным (5–6). Собранные отмечены звёздочкой. Листается пальцем и стрелками, как в пазле.
2. Тап по карточке → слева деревянная доска с бледными контурами деталей того же цвета и формы, справа на столе вразброс лежат детали в настоящий размер. Сова слева внизу: «Давай соберём домик!».
3. Касается детали → она приподнимается, сова: «Треугольник!». Тащит пальцем на доску (или тап по детали, потом тап по доске рядом с её местом). Деталь примагничивается, звук «положил», иногда короткая похвала.
4. Не то место → деталь мягко возвращается на стол, сова: «Это кружок. Найди место для кружка». После двух промахов подряд нужный контур светится.
5. Долго ничего не делает (~10 с) → сова: «Возьми детальку!».
6. Всё на месте → искорки и волшебный звук → фигуры превращаются в нарисованный предмет → он оживает по-своему → сова: «Ура! Получился домик!» → предмет вырастает, справа маленькая карточка «Ещё» со следующей несобранной.
7. «Галерея» в шапке всегда возвращает к выбору.

## Решения викторины

| Тема | Решение |
|---|---|
| Детали | Простые фигуры гуашевых цветов с лёгким объёмом и мягким контуром; рисует код, точно по размеру. Повороты не нужны: деталь лежит на столе уже в нужном положении |
| Формы | Круг, квадрат, треугольник, прямоугольник, звезда + **полукруг** и **овал** |
| Одинаковые детали | Одна и та же форма, размер и цвет (колёса, ушки, лепестки) подходят в любое такое место |
| Финал | Искорки → фигуры превращаются в нарисованный предмет (1 картинка владельца на фигурку) → предмет оживает → «Ура! Получился …!» → предмет крупно, сбоку «Ещё» |
| Пока нет картинки | Оживают сами собранные фигуры (то же движение) |
| Как оживает | Каждый по-своему: машинка и паровозик уезжают и возвращаются, ракета взлетает и опускается, рыбка и кораблик качаются на волне, бабочка машет крыльями, солнышко сияет, остальные весело подпрыгивают |
| Поле | Бледные контуры каждой детали того же цвета и формы (по умолчанию); в настройках можно «Серые контуры» — только форма |
| Раскладка | Доска-вкладыш слева, детали справа прямо на столе вразброс (как в пазле), сова слева внизу |
| Старт | Сначала галерея больших карточек (как в пазле) |
| Сложность | Галерея идёт от простых к сложным; «Ещё» — следующая несобранная по порядку; собранные со звёздочкой |
| Фигурки (16) | мороженое (2), грибок (2), рыбка (2), домик (3), снеговик (3), кораблик (3), яблочко (3), машинка (4), ракета (4), ёлочка (5), паровозик (5), котик Мяу (5), солнышко (5), бабочка (5), сова Олли (5), цветочек (6) |
| Детали не накладываются | Детали стыкуются краями; если деталь частично прячется (труба за крышей, ушки за головой), её место всё равно отдельное и видно |
| Голос | Сова (общий `createGamePresenter`, сова / Мяу по настройке хаба) |
| Имя при взятии | Каждый раз одним словом: «Кружок!», «Треугольник!» |
| Ещё фразы | Старт с именем фигурки; иногда короткая похвала; не то место + подсветка после 2 промахов; финал с именем; «Возьми детальку!» после ~10 с бездействия |
| Звук превращения | Один общий волшебный для всех фигурок |
| Взял / положил / промах | Общие `pickup.mp3` / `drop.mp3` / `soft-miss.mp3` (как в пазле и «Куда положить?») |
| Озвучка | Один длинный трек ElevenLabs тем же голосом, Cursor режет. Пока трека нет — сова говорит текстом в облачке |
| Фон | Светлый деревянный стол сверху, по краям кадра лёгкие намёки; центр спокойный |
| Доска | Деревянная доска-вкладыш для малышей: светлая рамка, внутри гладкое поле; контуры рисует код |
| Шестерёнка | Да, крайняя справа → раздел «Собери фигурку» в настройках хаба |
| Настройки | «Подсказка на поле»: цветные / серые контуры; «Начать заново» — сбросить звёздочки собранных |
| Звёздочки везде | Сброс звёздочек — в каждой игре, где галерея их отмечает (сейчас «Собери пазл»), в её разделе настроек |
