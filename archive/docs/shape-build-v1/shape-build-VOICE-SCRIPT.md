# «Собери фигурку» — текст для озвучки (mp3)

**Статус текста:** ЗАФИКСИРОВАНО (логика) 02.10.2026 по викторине · **озвучка:** ждём трек владельца.  
**Источник строк в коде:** `src/games/shape-build/phrases.ts`. Unit-тест сверяет этот файл с кодом строка в строку.  
**Папка mp3:** `public/assets/games/shape-build/voice/`. Имена файлов не менять без правки кода.

## Как записать

1. ElevenLabs, тот же голос, что в «Лопни шарик» и «Куда положить?». Спокойный темп сказки, без шёпота и без «строгого учителя».
2. Один длинный трек: все фразы **сверху вниз в этом порядке**, между фразами пауза ~1 секунда (в тексте для генерации ставьте пустую строку или `<break time="1s"/>`).
3. Можно частями (например, по разделам) — тогда имена `shape-build-voice-reel-1.mp3`, `-2.mp3`… в том же порядке.
4. Положите в `assets-master/games/shape-build/shape-build-voice-reel.mp3` и напишите «готово озвучка». Cursor нарежет на 63 файла тем же способом, что «Куда положить?».

Пока трека нет, сова говорит те же фразы текстом в облачке.
