**Как это соотносится с уже зафиксированными правилами продукта** (важно, чтобы не
показалось, что это новое/спорное решение):

- `Планета_Мяу_Идея_продукта.md` §14 «Три канала» **уже разрешает** канал
  «Сток звуков/изображений — только после проверки лицензии» — то, что ниже, это
  именно проверка лицензии для этого уже одобренного канала, не новое правило.
- §15 «Open-source reuse matrix» **уже разрешает** брать «идею/логику» механик у
  open-source аналогов (с проверкой лицензии) — тоже уже одобрено.
- §15 правило **«визуальные ассеты чужих репо не копировать»** — по смыслу это
  запрет тащить арт из конкретных чужих игр/приложений (например срисовывать/брать
  файлы из Toca Boca). Это **не то же самое**, что использование CC0/public domain
  стоков, которые авторы сами отдали в свободное использование — но чтобы не было
  двойного толкования, ниже для каждого источника явно указана лицензия и то, что
  именно с ней можно/нельзя делать.
- Правило анти-галлюцинаций проекта (п.7 списка запретов идеи): «не утверждать
  „найден open-source аналог" без записи конкретного репозитория и лицензии в

Zero-dependencies, есть рендер на Konva.js (опционально). | **ISC** (пермиссивная, аналог MIT — можно использовать в закрытом проприетарном коде без обязательства открывать свой код) | 4. **Итог по коду:** `headbreaker` + `interact.js` — оба реальные, актуальные (обновлялись
в 2026), пермиссивные лицензии (ISC/MIT), безопасны для проприетарного проекта. Это
может закрыть значительную часть механик игр 2.3/2.4/2.5 без написания drag&drop-логики
с нуля.

## 2. Готовые бесплатные наборы изображений

**Честная оценка стиля:** ни один из найденных бесплатных паков не сделан в точном
стиле «книжная иллюстрация, гуашь/акварель» (направление А, уже выбранное для проекта,
`docs/09-VISUAL-DESIGN-RESEARCH.md`). Бесплатные паки — это почти всегда **плоский
вектор** («flat cartoon»), не живопись. Поэтому ниже — честное разделение: что можно
брать как финальный ассет, а что — только как заготовку для разработки/референс.

**Итог по картинкам:** реального «готового финального» набора в нужном стиле для
героев/иллюстраций **не нашлось** — ваш план генерировать через Nano Banana Pro
остаётся основным для банка объектов, Мяу и сцен. Но **Kenney Game Icons** —
настоящий кандидат сэкономить генерацию 5 UI-иконок, а **Kenney/OpenGameArt
CC0-паки животных** — хороший способ быстро получить рабочие заготовки для кода игр,
пока финальный арт не готов.

| Freesound.org (общий поиск с фильтром «CC0») | разные авторы | Зависит от звука — **фильтровать по CC0** на сайте | Инструменты, транспорт, всё что угодно | Хороший общий источник, но трудозатратно (нужно слушать и выбирать вручную по одному) |

**Альтернатива, которая может закрыть большую часть звуков без похода по стокам:**
раз вы уже выбрали **ElevenLabs**, у него есть отдельная модель
**`eleven_text_to_sound_v2`** — генерирует короткий звук прямо из текстового описания
(например «мягкое мяуканье кота» или «мягкий хлопок шарика без резкого звука») без
поиска по лицензиям. Промпт-шаблон — `GENERATION-GUIDE.md` §11. Это может оказаться
быстрее, чем перебирать Freesound по одному файлу — решать вам после первого теста.
