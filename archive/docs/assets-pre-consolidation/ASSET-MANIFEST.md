## Правило именования и путей

- Файлы изображений: `public/assets/<категория>/<id>-<slug>.png`
  (латиница, kebab-case — русские имена файлов вызывают проблемы на разных ОС/URL).
- Звук: `public/assets/audio/<категория>/<id>-<slug>.mp3`
  (формат `.mp3` — уже указан в `vite.config.ts` → `workbox.globPatterns`, ничего
  менять в конфиге не нужно).
- `<id>` — короткий код из таблиц ниже (например `PET-01`), чтобы легко искать файл
  по манифесту и в коде.
- Прозрачность: объекты банка (для drag&drop/сортировки/пазла) — **PNG с прозрачным
  фоном**. Полноэкранные сцены (фоны зон, пазл-картинки, сцены прятки) — **без
  прозрачности**, полноценная иллюстрация с фоном.

## Аудио (звуки, музыка, голос)

Nano Banana Pro генерирует только **изображения** — для звука нужен другой инструмент
(это не придумано мной как ограничение, а факт: официальная документация Gemini/Nano
Banana Pro описывает только image generation). Способ генерации звука/голоса — открытый
вопрос, см. таблицу ниже и раздел «Открытые решения» в конце файла.
