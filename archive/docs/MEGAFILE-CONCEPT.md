# Мегафайл ассетов — концепт (собрать позже)

**Дата:** 22 сентября 2026
**Статус:** ЗАФИКСИРОВАНО — концепт. Сам файл **ещё не собирается**.
**Решение владельца:** путь А. Сначала игра на простых фигурах. Мегафайл — после
того, как игра уже собрана и видно, какие картинки, спрайты и звуки реально нужны.

Черновики, которые уже есть и **не заменяют** будущий мегафайл:
`ASSET-MANIFEST.md`, `GENERATION-GUIDE.md`, `FREE-RESOURCES-RESEARCH.md`.

---

## Когда собирать

1. Оболочка и 9 игр работают на заглушках (цветные фигуры, текущий `favicon.svg`,
   при необходимости уже скачанные CC0-файлы только как временные).
2. По экранам видно: какие кадры анимации нужны, какие размеры, какие звуки
   реально играют.
3. Тогда один документ заменяет разрозненные таблицы и промпты. Владелец идёт
   по нему сверху вниз и генерирует контент, потом файлы подключаются в игру.

До этого шага **не** генерировать банк из 106 объектов и **не** качать пачками
новые стоки «на всякий случай».

---

## Что будет внутри (один файл, одна строка = один ассет)

Картинки и звуки — в разных таблицах, но в одном документе.

### Картинка (каждая, включая фон, меню, пазл, favicon)

Столбцы, без пропусков:

| Столбец | Зачем |
|---|---|
| ID | Короткий код, как в текущем манифесте (`PET-01`, `UI-01`) |
| Где в игре | Зона, игра, меню, карта, заставка |
| Назначение | Что это на экране |
| Имя файла | Латиница, kebab-case |
| Путь | `public/assets/...` |
| Формат | PNG или SVG |
| Расширение | `.png` / `.svg` |
| Разрешение | Пиксели, например 1024×1024 |
| Соотношение сторон | `1:1`, `4:3`, `16:9` |
| Прозрачность | Да (объект) или нет (сцена) |
| Промпт | Готовый текст для Nano Banana Pro, в этой же строке |
| Референс на входе | Какой уже одобренный файл приложить (REF-01… или предыдущий кадр) |
| Статус | Заглушка / нужно сгенерировать / сгенерировано / проверено |

Обязательные группы строк (ничего не забыть):

- 4 стилевых референса (генерируются первыми, в игру не идут)
- банк объектов
- позы Мяу
- шарики, погода, корзинки сортировки, фигуры конструктора
- 6 пазл-сцен, 3 сцены пряток
- фоны welcome / меню, **9 иконок игр**, спрайты Мяу-ведущего
- ~~5 плиток карты зон~~ — устарело 22.09.2026
- экраны меню / родительский центр
- UI-иконки
- **favicon и иконки PWA** — логотип хаба «Планета Мяу»: исходник для генерации
  плюс размеры, которые ставит сайт (сейчас заглушка `public/favicon.svg`;
  для PWA ещё нужны PNG 192 и 512 — известная дыра K-002)

### Спрайт-анимация (отдельная таблица, не смешивать с одиночными картинками)

На каждую анимацию:

- ID и где играет (лопнул шарик, Мяу жуёт, умывается, и т.д.)
- Кадр-основа и какой референс держать одинаковым
- Список кадров по порядку (отдельные PNG, не один файл сразу)
- Сколько кадров, длительность кадра
- Чем склеить в лист — сервис ниже
- Итоговое имя spritesheet, когда код уже умеет его читать

Сервисы склейки (проверены 22.09.2026, бесплатно в браузере). Предпочитать те,
где картинка **не уходит на чужой сервер**:

| Сервис | Адрес | Заметка |
|---|---|---|
| I Love Sprites | https://ilovesprites.com/ | В браузере, файлы не загружаются на сервер (так пишет сайт) |
| SpritePilot | https://spritepilot.com/ | В браузере; один режим «авто» может отправить файл — его не использовать |
| ezgif GIF → sprite sheet | https://ezgif.com/gif-to-sprite | Файл уходит на их сервер и удаляется через час — только если локальные инструменты не подошли |
| Leshy SpriteSheet Tool | https://www.leshylabs.com/apps/sstool/ | Бесплатно пользоваться на их сайте; программу себе забирать нельзя (их лицензия это запрещает) |

### Звук (отдельная таблица)

На каждый файл: ID, роль (тап, хлопок, животное, фон зоны, голос, буква, счёт),
формат `.mp3`, длительность, промпт для Suno или ElevenLabs, папка кандидатов,
какой файл выбран. Скачивание пачек стоков — в момент сборки мегафайла, не раньше.
Уже лежащие 16 UI-кандидатов в `public/assets/_candidates/ui-sounds/` остаются;
выбор финала — когда игра уже пищит этими ролями.
